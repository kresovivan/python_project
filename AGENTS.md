# Инструкции для ИИ-агентов (AGENTS.md)

Репозиторий для изучения Python. Главный проект — `english_for_programmers_gui`
(тренажёр английского и китайского, GUI на CustomTkinter).

## Перед работой

- Полные правила главного проекта — в `english_for_programmers_gui/CLAUDE.md`,
  читай его перед изменениями в этом проекте.
- Общаемся по-русски, простым языком, объяснять «почему».
- Комментарии в коде — на русском, без эмодзи и спецсимволов (без длинного
  тире, стрелок, галочек; вместо них обычный дефис `-`).

## Правила

- Не ставить пакеты через `pip` и не удалять без явной просьбы.
- Перед изменениями читать файл целиком: пользователь часто правит файлы сам.
- После изменений — запускать и проверять (тесты, при необходимости снимок экрана).

Тесты в `english_for_programmers_gui`:

```text
python -m unittest discover -s tests -t .
```
