# Инструкции для ИИ-агентов (AGENTS.md)

Репозиторий для изучения Python. Проекты:

- `english_for_programmers_gui` - главный: тренажёр английского
  и китайского, GUI на CustomTkinter. Полные правила -
  в `english_for_programmers_gui/CLAUDE.md`, читай его перед
  изменениями в этом проекте.
- `kisunchik_pet` - настольный питомец Кисунчик: живёт на рабочем
  столе и помогает учить английский тем же словарём (4070 слов
  тренажёра + азбука). Полные правила - в `kisunchik_pet/CLAUDE.md`,
  читай его перед изменениями: там про Kaspersky (запуск только через
  pythonw, не exe), озвучку (SAPI + Google TTS), дневник обучения
  (`progress.json`), принципы пузыря и вёрстки под масштаб 200%.

## Перед работой

- Общаемся по-русски, простым языком, объяснять «почему».
- Комментарии в коде - на русском, без эмодзи и спецсимволов (без
  длинного тире, стрелок, галочек; вместо них обычный дефис `-`).

## Правила

- Не ставить пакеты через `pip` и не удалять без явной просьбы.
- Перед изменениями читать файл целиком: пользователь часто правит
  файлы сам.
- После изменений - запускать и проверять (тесты, при необходимости
  снимок экрана).

Тесты в каждом проекте запускаются из его папки:

```text
python -m unittest discover -s tests -t .
```

## Коммиты

- Коммитить только файлы текущей задачи, чужие незакоммиченные
  изменения пользователя не трогать.
- Не коммитить журналы и локальные настройки: `pet.log`, `settings.json`.
- `progress.json` (дневник обучения) пользователь хранит в git сам -
  в свои коммиты его не включать.
