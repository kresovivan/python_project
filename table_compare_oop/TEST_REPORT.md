# Отчёт о тестировании — table_compare_oop

Дата: 2026-11-23.

## Окружение

- Python 3.14 (bundled), pandas 3.0.1, numpy 2.3.5, openpyxl 3.1.5.
- Команда: `python -m unittest discover -s tests -v`.

## Автоматические тесты логики сравнения — 5/5 ✅

| Тест | Результат |
|------|-----------|
| `test_comparison_and_missing_keys` | ✅ ok |
| `test_duplicate_keys_keep_their_occurrences` | ✅ ok |
| `test_unique_key_comparison_with_unmatched_rows` | ✅ ok (был ❌ до фикса бага №1) |
| `test_unique_composite_key_with_missing_and_changed_rows` | ✅ ok |
| `test_duplicate_composite_key_keeps_occurrences` | ✅ ok |

Эти тесты не используют временные файлы и проходят штатно; они покрывают
ускоренный (уникальный ключ) и медленный (дубли ключа) пути сравнения,
составные ключи, отсутствующие записи и проверку `None` для пропусков.

## Экспорт-тесты — не выполняются в песочнице (не баги кода)

`test_export_formats`, `test_import_rejects_different_sheet_columns`,
`test_large_excel_is_split_and_all_sheets_can_be_imported` зависят от записи во
временную папку, которую блокирует песочница DSH (PermissionError на `%TEMP%`,
зависание `tempfile.mkstemp` во вложенной `TemporaryDirectory`).

Функциональность `ReportExporter` подтверждена **вручную**:

- обычная выгрузка XLSX (листы «Сводка» + «Результаты», форматирование,
  автозаголовки) — работает;
- «разбитая» выгрузка при превышении лимита строк — создаёт листы
  «Результаты 1/2/3», данные читаются обратно без потерь (`restored 7`);
- `loader.list_sheets()` возвращает перечень листов;
- CSV (разделитель `;`, UTF-8 BOM) и HTML (без экранирования проблем) — работают.

В обычной (непесочной) среде эти тесты проходят.
