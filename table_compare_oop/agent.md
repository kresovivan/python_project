# agent.md — соглашения и правила для агентов в этом репозитории

## Что это за проект

`table_compare_oop` — Tkinter-приложение для построчного сравнения двух и более
выгрузок (CSV / XLSX / XLS) по общему ключу. Выводит совпадения, отличия и
отсутствующие записи; экспортирует результат в CSV / XLSX / HTML.

## Как работаем с кодом

- Код объектно-ориентированный. Не переписывайте его «на ООП» без цели: правки
  должны быть точечными и сохранять публичные методы классов `TableLoader`,
  `TableComparator`, `ReportExporter`, `StatisticsAnalyzer`, `MainWindow`.
- **Инвариант данных:** пропуски в результате — это `None` (не `nan`, не `pd.NA`).
  При добавлении колонок в `compare()`/`_compare_unique_keys()` прогоняйте результат
  через `_finalize()` (или присваивайте `pd.Series(..., dtype=object)`).
- Чтение в pandas 3.x с последующей записью — через `to_numpy(dtype=object, copy=True)`.
- Горячие участки сравнения уже векторизованы (`str.cat`, `np.where`, `Series.mask`).
  Не возвращайте построчные Python-циклы по ячейкам.
- Долгие операции — только в фоновых потоках; в GUI — только через `self._post(...)`.
- Имена файлов в колонках — через `table_compare.naming.unique_short_names()`, чтобы
  два файла с одинаковым именем не дали коллизию `Файл::поле`.

## Проверка изменений

```powershell
py -m unittest tests.test_all_functions -v   # все функции (использует examples/test_A|B.csv)
py -m unittest discover -s tests -v          # весь набор
```

- Логические тесты (`test_*_keys*`, `test_comparison_*`, `test_summarize`,
  `test_save_*`, `test_load_*`) обязаны проходить.
- Экспорт-тесты пишут во временную папку; в песочнице задавайте `TEST_TMPDIR`
  (см. `writable_dir()` в `tests/test_all_functions.py`), чтобы обойти запрет
  записи в `%TEMP%`.
- GUI-изменения невозможно прогнать автоматически без дисплея — проверяйте хотя бы
  компиляцию (`python -c "import table_compare.ui.main_window"`) и делайте ручной
  визуальный smoke-тест.

## Стиль

- UI-текст и комментарии — на русском; код — PEP 8.
- Новую логику сравнения/экспорта покрывайте тестом в `tests/`.
- Не меняйте значения в `table_compare/config.py` без обновления всех потребителей
  (`statistics.py`, `exporter.py`, `main_window.py`, тесты).
- Пользовательская документация — в `MANUAL.md`; держите её актуальной.
