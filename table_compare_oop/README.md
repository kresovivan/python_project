# Сравнение таблиц CSV / Excel

Настольная программа для сверки двух и более выгрузок по выбранному ключу.
Открывает CSV, XLSX и XLS; отображает совпадения, отличия и отсутствующие
записи. Выгружает полный результат в CSV, XLSX и HTML.

## Запуск

Нужен Python 3.10 или новее и установленный Tkinter (обычно входит в Python
для Windows). В PowerShell сначала перейдите в папку `table_compare_oop`,
где находятся `requirements.txt` и `run.py`, затем выполните:

```powershell
py -m pip install -r requirements.txt
py run.py
```

Если виртуальное окружение `.venv` лежит на уровень выше папки проекта,
используйте его Python вместо `py`:

```powershell
& ..\.venv\Scripts\python.exe -m pip install -r .\requirements.txt
& ..\.venv\Scripts\python.exe .\run.py
```

В VS Code запускайте `run.py`. Файл `table_compare\__init__.py`
не предназначен для запуска программы.

В Linux используйте `python3` вместо `py`; пакет Tkinter может
устанавливаться отдельно через менеджер пакетов системы.

## Как сравнить файлы

1. Добавьте минимум два CSV/Excel-файла. Если в книге Excel несколько листов,
   отметьте нужные листы в открывшемся окне. Их данные объединятся в одну
   таблицу для этого файла; названия столбцов должны совпадать.
2. Выберите общий ключ, например "Номер". Несколько выбранных столбцов
   составляют составной ключ.
3. Выберите поля для сравнения. Дополнительные поля попадут в отчёт без
   участия в расчёте статуса.
4. Нажмите "Сравнить". Полный результат доступен для экспорта.

Для первой проверки в папке `examples` лежат два CSV по 500 записей.
Если выбрать ключ "Номер" и остальные четыре поля для сравнения,
результат: 478 совпали, 12 отличаются, 20 записей без пары.

При сравнении двух файлов по уникальному ключу из одного или нескольких
столбцов программа использует ускоренный способ сопоставления. Если
сочетания значений ключа повторяются, записи сравниваются по порядку
повторений. Время работы
зависит от размера файлов, выбранных полей, памяти и скорости диска.

В окне показываются первые 5 000 строк. Экспорт содержит все записи.
Если результат не помещается на один лист Excel, программа создаёт листы
"Результаты 1", "Результаты 2" и так далее. На каждом листе не более
1 048 575 записей плюс строка заголовков. При повторном импорте такого
файла выбирайте листы "Результаты"; лист "Сводка" предварительно снят
с выбора. При очень крупных файлах загрузка и сравнение используют память
пропорционально объёму данных.

## Структура проекта

- `table_compare/loader.py` - чтение файлов и время загрузки;
- `table_compare/comparator.py` - сопоставление по ключу и дубликатам;
- `table_compare/statistics.py` - показатели по полям и файлам;
- `table_compare/exporter.py` - экспорт результатов;
- `table_compare/ui/` - интерфейс, окна и оформление;
- `run.py` - запуск программы;
- `requirements.txt` - зависимости.

Проверить расчёт и экспорт можно командой:

```powershell
py -m unittest discover -s tests -v
```
