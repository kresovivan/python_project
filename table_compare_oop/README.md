# Сравнение таблиц CSV / Excel

Настольная программа на Python/Tkinter для сверки двух и более выгрузок
(CSV, XLSX, XLS) по общему ключу. Показывает совпадения, отличия и строки,
которых нет в одном из файлов; выгружает полный результат в CSV, XLSX и HTML.

Код написан в объектно-ориентированном стиле; сопоставление выполняется
векторизованно (без построчных циклов), поэтому работает быстро даже на
больших таблицах.

## Возможности

- Автоопределение кодировки и разделителя CSV (`,` / `;` / табуляция / `|`).
- Загрузка нескольких листов Excel (с объединением в одну таблицу).
- Ключ из одного или нескольких полей (составной ключ).
- Корректная обработка дублей ключа (по порядку повторений) и пробелов по краям.
- Сравниваемые и дополнительные поля, общий «Флаг расхождения» по строке.
- Ускоренный путь для двух файлов с уникальным ключом.
- Цветная таблица результатов + цветные плитки-итоги.
- Фильтр «Только расхождения», **поиск** по таблице, **сортировка** по клику.
- **Копирование в буфер обмена** (TSV).
- Экспорт **XLSX / CSV / HTML**, в том числе **только расхождения**.
- Для больших результатов XLSX делится на листы «Результаты 1, 2, …».
- Окно «Подробная статистика» по полям и по файлам.

## Запуск

Нужен Python 3.10+ и Tkinter (в Python для Windows входит по умолчанию).
В PowerShell перейдите в папку `table_compare_oop` и выполните:

```powershell
py -m pip install -r requirements.txt
py run.py
```

Если виртуальное окружение `.venv` лежит на уровень выше папки проекта:

```powershell
& ..\.venv\Scripts\python.exe -m pip install -r .\requirements.txt
& ..\.venv\Scripts\python.exe .\run.py
```

Если проект установлен как пакет (`pip install .`), доступна команда:

```text
table-compare
```

В Linux используйте `python3` вместо `py`.

## Как пользоваться

Подробная пошаговая инструкция — в [MANUAL.md](MANUAL.md). Коротко:

1. **«Добавить файлы»** — выберите 2 и более CSV/Excel-файла.
2. **Шаг 2** — выберите ключ (Ctrl+клик — несколько полей составного ключа).
3. **Шаг 3** — отметьте сравниваемые и дополнительные поля.
4. **«Сравнить»** — на вкладке результата таблица, плитки-итоги,
   фильтр/поиск/сортировка, кнопки экспорта.

## Тестовые данные и тесты

В `examples/` лежат компактные `test_A.csv` (разделитель `,`) и `test_B.csv`
(`;`), покрывающие дубли ключа, отсутствующие записи, отличия и пробелы в ключе.
Ожидаемый итог по ключу «Номер»: **Совпадает 5 · Отличается 3 · Нет строки 2**
(10 записей).

Запуск всех тестов:

```powershell
py -m unittest discover -s tests -v
```

Только комплексный тест всех функций:

```powershell
py -m unittest tests.test_all_functions -v
```

## Структура проекта

- `table_compare/loader.py` — `TableLoader`: чтение CSV/Excel, автодетект, листы;
- `table_compare/comparator.py` — `TableComparator`: сопоставление по ключу и дублям;
- `table_compare/statistics.py` — `StatisticsAnalyzer`: показатели по полям/файлам;
- `table_compare/exporter.py` — `ReportExporter`: экспорт CSV/XLSX/HTML;
- `table_compare/naming.py` — уникальные короткие имена файлов;
- `table_compare/config.py` — статусы, палитра, шрифты;
- `table_compare/ui/` — интерфейс, окна, оформление;
- `run.py` — точка входа; `pyproject.toml` — оформление пакета;
- `MANUAL.md` — инструкция пользователя;
- `tests/` — `test_workflow.py`, `test_all_functions.py`;
- `examples/` — тестовые CSV.
