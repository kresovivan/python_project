# Инструкция пользователя — «Сравнение таблиц (CSV / Excel)»

Программа сверяет две и более таблицы (CSV или Excel) по общему ключу и показывает,
где данные совпали, где различаются и где строки нет в одном из файлов.

---

## 1. Запуск

Нужен Python 3.10+ с библиотекой Tkinter (в Python для Windows идёт по умолчанию).

В PowerShell перейдите в папку программы и выполните:

```powershell
py -m pip install -r requirements.txt
py run.py
```

Если зависимости уже стоят, достаточно `py run.py`.

---

## 2. Шаг 1 — Добавьте файлы

1. Нажмите **«Добавить файлы»** и выберите 2 и более файлов CSV или Excel.
2. Если в книге Excel несколько листов, откроется окно **«Листы Excel»** —
   отметьте листы с одинаковыми столбцами (их строки объединятся в одну таблицу).
3. Программа сама определит кодировку и разделитель CSV (`,` или `;`).

Список выбранных файлов появится внизу, а рядом — счётчик «Файлов: N».

---

## 3. Шаг 2 — Выберите ключ

Ключ — это «имя» строки, по которому строки из разных файлов считаются одной записью
(обычно `id`, `guid`, `номер` и т.п.).

- Клик — выбрать одно поле.
- **Ctrl+клик** — добавить/снять отдельное поле.
- **Shift+клик** — выделить диапазон.

Можно выбрать несколько полей — получится **составной ключ** (строки совпадут только
при равенстве всех выбранных полей). Подсказка под списком объясняет текущий выбор.

---

## 4. Шаг 3 — Выберите сравниваемые и дополнительные поля

- **Сравниваемые поля** (список слева) — по ним считается статус
  «Совпадает / Отличается / Нет строки» и формируется флаг расхождения строки.
- **Дополнительные поля** (список справа) — просто выводятся в отчёт без статуса
  (удобно для контекста).

Одно и то же поле нельзя сделать одновременно сравниваемым и дополнительным —
при выборе в одном списке оно снимается в другом. Ключевое поле можно дополнительно
отметить здесь, чтобы увидеть его значения по каждому файлу отдельной колонкой.

Кнопки **«Все»** и **«Ничего»** отмечают или снимают весь список сразу.

---

## 5. Сравнение

Нажмите **«Сравнить»**. Окно развернётся и откроется вкладка
**«Результат и расхождения»**.

Вверху — **цветные плитки-итоги** и сводка:

| Цвет | Значение |
|------|----------|
| 🟩 зелёный | Совпало |
| 🟥 светло-красный | Отличается |
| 🟥 тёмно-красный | Нет строки |

Под плитками — скорость загрузки и сопоставления.

---

## 6. Таблица результатов

Колонки:

- **Ключ** — склеенное значение ключа (для составного — через ` | `).
- **Флаг расхождения** — «Есть расхождение» / «Нет расхождения» по всей строке.
- **Файл::ключ** — значение ключа в конкретном файле (пусто, если строки там нет).
- **Файл::поле** — значение поля в конкретном файле.
- **Поле::статус_сверки** — статус сравнения по полю.

Цвет строки выбирается по «самому серьёзному» статусу: Нет строки → Отличается →
Совпадает.

### Полезные действия с таблицей

- **Сортировка** — щёлкните по заголовку колонки; повторный щелчок меняет порядок
  (по возрастанию ↔ по убыванию).
- **Только расхождения** — галочка слева от таблицы оставляет записи, где что-то
  не сошлось.
- **Поиск** — введите текст в поле «Поиск:», таблица отфильтруется по всем колонкам
  (без учёта регистра).
- **Копировать (TSV)** — копирует отфильтрованную таблицу в буфер обмена
  (разделитель — табуляция, удобно вставлять в Excel).
- **Подробная статистика** — открывает окно со сводкой по полям и по файлам.

> В окне показаны первые 5 000 строк, чтобы интерфейс не «тормозил». Экспорт всегда
> содержит весь результат.

---

## 7. Экспорт

Кнопки: **Экспорт XLSX**, **Экспорт CSV**, **Экспорт HTML**.

- **XLSX** — лист «Сводка» (итоги, различия по полям, загрузка файлов) + лист
  «Результаты». Для очень больших результатов создаются листы
  «Результаты 1», «Результаты 2» и т.д.
- **CSV** — разделитель `;`, кодировка UTF-8 с BOM (открывается в Excel без «кракозябр»).
- **HTML** — таблица с цветовой раскраской по статусам (открывается в браузере).

**Экспорт только расхождений** — отметьте галочку слева от кнопок экспорта, и в
файл попадут только записи с расхождением (при этом «Сводка» в XLSX пересчитывается
под это подмножество).

---

## 8. Чтение выгруженного XLSX обратно

Если вы ранее выгрузили большой XLSX, разбитый на листы «Результаты N», при повторном
открытии в программе выберите листы «Результаты» (лист «Сводка» программа заранее
снимает с выбора, так как его колонки отличаются).

---

## 9. Советы

- Перед сравнением убедитесь, что названия столбцов совпадают во всех файлах
  (программа сопоставляет по именам).
- Ключи сравниваются без учёта пробелов по краям: `« 7 »` и `«7»` считаются одним
  значением.
- При дубликатах ключа строки сопоставляются по порядку повторений внутри ключа.
- Для очень больших файлов используйте CSV вместо XLSX — загрузка и память расходуются
  пропорционально объёму данных.

---

## 10. Быстрая проверка

В папке `examples` лежат `test_A.csv` и `test_B.csv` (и большие
`compare_A_500.csv` / `compare_B_500.csv`). Откройте их, выберите ключ «Номер» и
сравниваемые поля «Статус», «Сумма» — увидите совпадения, отличия и отсутствующие
записи.
