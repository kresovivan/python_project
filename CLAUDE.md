# python_project — учебный репозиторий по Python

Репозиторий для изучения Python: тренажёр английского и китайского, учебные
скрипты по книгам, другие небольшие проекты.

## Главный проект: english_for_programmers_gui

Тренажёр английского и китайского для программистов (GUI на CustomTkinter).
Это основной, самый большой и зрелый проект репозитория. У него есть свой
`english_for_programmers_gui/CLAUDE.md` с полными правилами — читай его
перед любыми изменениями в этом проекте.

Код проекта написан в стиле ООП:

- `core/` — логика без окон: классы `Word`, `Vocabulary`, `Lesson`, `Session`,
  `Progress`, `Language`, `GrammarTopic`, `Table`, `AnswerChecker` и др.
- `gui/` — интерфейс: `App`, `Page` и наследники `HomePage`, `AlphabetPage`,
  `GrammarPage`, `CardsPage`, `ChoicePage`, `TypingPage`, `DictionaryPage`...
- наследование: `SoundsPage(GrammarPage)`, `PinyinChecker(AnswerChecker)`,
  `CardsPage(StudyPage)`, абстрактные `VoiceEngine(ABC)` и `StudyPage(Page, ABC)`;
- датаклассы с `frozen=True` для данных: `Word`, `Table`, `GrammarTopic`, `Language`;
- полиморфизм: язык сам выбирает проверяющего (`Language.checker`) и «тетрадь»
  грамматики (`book()`);
- внедрение зависимостей снаружи: `App(..., speaker=)`, `Progress(path, today=)`.

Тесты в `tests/unit`, `tests/gui`, `tests/system` — в стиле TDD.

## Проект kisunchik_pet

Настольный питомец Кисунчик: прозрачное окно поверх рабочего стола,
спрайтовая анимация, клики по зонам тела, учит английскому словам
с озвучкой. У него есть свой `kisunchik_pet/CLAUDE.md` с устройством
и подводными камнями - читай его перед изменениями в этом проекте.

## Общие правила

- Общаемся по-русски, простым языком, объяснять «почему».
- Комментарии в коде — на русском, без эмодзи и спецсимволов (без длинного
  тире, стрелок, галочек; вместо них обычный дефис `-`).
- Не ставить пакеты через `pip` и не удалять без явной просьбы.
- Перед изменениями читать файл целиком: пользователь часто правит файлы сам.
- После изменений — запускать и проверять (тесты, при необходимости снимок экрана).
