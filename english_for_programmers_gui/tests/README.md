# Тесты English for Programmers

Этот набор нужен, чтобы изменения в программе не ломали незаметно уже работающие возможности.
Например, можно поменять оформление и случайно потерять сохранение занятия, а можно изменить
словарь и получить упражнение без правильного варианта ответа. Автоматические тесты быстро
проверяют такие правила без ручного прохода по всем страницам.

Используется `unittest` из стандартной библиотеки Python. Устанавливать pytest или другие
тестовые библиотеки не нужно. Все команды ниже выполняются из корня проекта
`english_for_programmers_gui/`.

## Быстрый запуск

```text
python -m unittest discover -s tests -t . -v
```

Эта команда проверяет логику, словарь, компиляцию, мониторы, GUI и закрытие `main.py`.
Реальные звук и сборка exe по умолчанию пропускаются. Сейчас нормальный результат:
`OK` и два пропущенных необязательных теста.

Запуск только нужной части:

```text
python -m unittest tests.test_core -v
python -m unittest tests.test_vocabulary -v
python -m unittest tests.test_screen tests.test_source -v
python -m unittest tests.test_gui -v
python -m unittest tests.test_speech -v
```

## Что проверяют файлы

| Файл | Назначение |
|---|---|
| `test_core.py` | Проверка ответов, подсказок, сессий, статусов слов, серии дней, подбора слов, повтора ошибок, сохранения и восстановления занятий. Это правила программы, которые не зависят от окон. |
| `test_vocabulary.py` | Целостность 3621 слова и 18 тем, поиск, загрузка файлов, отвлекающие переводы. Отдельно ловит повторяющиеся варианты в выборе перевода. |
| `test_screen.py` | Геометрия окна на маленьких, больших и нескольких мониторах, отрицательные координаты, восстановление сохранённого положения. |
| `test_source.py` | Компиляция всех Python-файлов во временную папку и импорт приложения. Помогает найти синтаксические ошибки и проблемы импортов до запуска окна. |
| `test_gui.py` | Настоящие виджеты: навигация, горячие клавиши в русской раскладке, карточки, выбор, ввод слов, словарь, статистика, сброс, восстановление и WM_CLOSE. Также проверяет, что даты графика не выходят за холст. |
| `test_speech.py` | Правила кэша звука. По требованию проверяет настоящие edge-tts, MP3, медленную речь, системный голос и завершение фонового процесса. |
| `test_build.py` | По требованию собирает exe во временной копии, запускает его, проверяет ресурсы, сохранение настроек и закрытие через WM_CLOSE. |
| `support.py` | Общие средства: временные ресурсы, события клавиш, обработка цикла окна и функции Windows. |

## Полная проверка со звуком и сборкой

В PowerShell:

```powershell
$env:EFP_AUDIO_TESTS = "1"
$env:EFP_BUILD_TESTS = "1"
python -m unittest discover -s tests -t . -v
Remove-Item Env:EFP_AUDIO_TESTS
Remove-Item Env:EFP_BUILD_TESTS
```

Для звука нужны интернет и edge-tts. Во время проверки будут слышны английские фразы.
Сборка использует PyInstaller и `--no-shortcut`: ярлык на рабочем столе не создаётся.
Исходная папка `dist/` не перезаписывается.

Можно запустить необязательные проверки отдельно:

```powershell
$env:EFP_AUDIO_TESTS = "1"
python -m unittest tests.test_speech -v
Remove-Item Env:EFP_AUDIO_TESTS

$env:EFP_BUILD_TESTS = "1"
python -m unittest tests.test_build -v
Remove-Item Env:EFP_BUILD_TESTS
```

## Ручные проверки

Прослушать шесть слов через настоящий модуль озвучки:

```text
python -m tests.listen_words
```

Открыть приложение, начать карточки и вызвать звук клавишей `P` через обработчик GUI:

```text
python -m tests.manual_app_sound
```

Окно останется открытым. После его закрытия временные данные будут удалены.

Измерить скорость переключения страниц и изменения размера окна:

```text
python -m tests.benchmark_gui
```

Это измерение, а не тест с жёстким порогом: результат зависит от монитора, масштаба Windows
и загрузки компьютера. Красоту интерфейса и качество произношения автоматический тест оценить
не может. Их нужно проверять глазами и на слух, а техническую часть проверяют автотесты.

## Исправленные ошибки и expectedFailure

Если тест нашёл ошибку, которую пока не исправили, его можно отметить
`@unittest.expectedFailure` ("ожидаемая ошибка"). Тогда он не портит общий результат,
но сохраняет способ воспроизвести ошибку. Когда ошибку исправят, тест покажет
`unexpected success`: значит, декоратор пора удалить, и тест станет обычной защитой
от возврата ошибки.

Так было с двумя тестами, сейчас обе ошибки исправлены и декораторы удалены:

1. `test_distractors_are_unique` - в выборе перевода повторялись варианты, потому что у
   синонимов одинаковый перевод ("shut down" и "turn off" - оба "выключить").
   Исправлено в `Vocabulary.distractors`: повторы переводов убираются перед выбором.
2. `test_chart_date_labels_fit_inside_canvas` - даты под графиком обрезались при масштабе
   экрана 200%. Исправлено в `StatsPage.draw_chart`: отступы и шрифт умножаются на масштаб.

## Безопасность данных

Тесты используют временные копии `data/`, отдельные временные `user_data/` и временный аудиокэш.
Ваши настоящие `progress.json`, `state.json`, аудиокэш, готовая сборка и ярлык не изменяются.
Временные папки удаляются после завершения проверок.
