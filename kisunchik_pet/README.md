# kisunchik_pet - настольный питомец Кисунчик

Рыже-белый котик живёт на рабочем столе Windows: машет лапкой, кувыркается,
ест рыбку, сам гуляет по всем мониторам, когда пользователь долго не трогает
мышку. Плюс помогает учить английский: показывает слова с переводом
и произносит их голосом - офлайн голосом Windows (Zira, en-US) или
онлайн-голосом Google с выбором акцента.

## Запуск

Ярлык `Kisunchik` на рабочем столе (создаётся `make_shortcut.ps1`) или:

```text
pythonw run.py
```

Запуск идёт через установленный pythonw, а не через exe. Это осознанное
решение: на машине стоит Kaspersky, и он помещает свежесобранный exe
в ограниченную группу - ему запрещены запись автозапуска в реестр,
создание временной папки (onefile падал с "Could not create temporary
directory!") и даже доступ к голосам SAPI (Speak: 0x8004503a).
Интерпретатор python у Kaspersky доверенный, поэтому из-под него
работает всё. Если очень нужен exe - добавьте `KisunchikPet.exe`
в доверенные приложения Kaspersky и соберите командой из раздела
"Сборка exe" (только onedir).

Автозагрузка Windows включается и выключается галочкой в меню настроек
("Запускать вместе с Windows"). Запись живёт в реестре
(`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение `KisunchikPet`).
Если антивирус запрещает программе менять автозапуск - котик честно
возвращает галочку обратно, показывает пузырь с пояснением и пишет
в `pet.log`; тогда запись можно поправить вручную или разрешить
программе в антивирусе.

## Управление

- Клик по голове - показать новое английское слово с переводом.
- Клик по животику - произнести слово по-английски (карточка не прячется).
- Клик по хвосту - котик возмущается, карточка закрывается.
- Двойной клик - прыжок от радости.
- Перетаскивание мышкой - переместить на любое место любого монитора.
- Правый клик - меню настроек и выход.

## Настройки (правый клик по котику)

Размер котика, время засыпания, частота затей и прогулок, автопоказ слов,
озвучка голосом, самостоятельные прогулки, автозапуск с Windows.
Хранятся в `settings.json` рядом с программой, применяются сразу.

### Голос озвучки

Меню "Голос озвучки" предлагает два семейства голосов:

- Офлайн (работают без интернета): голос Windows Zira в пяти характерах -
  как есть, медленно и чётко, быстро, низкий и высокий (темп и высота
  задаются через SSML). Если в системе появятся другие английские голоса
  SAPI, они тоже покажутся в меню.
- Онлайн (нужен интернет): бесплатный Google Translate TTS без ключа,
  четыре акцента - американский, британский, австралийский, индийский.
  Мелодия скачивается в mp3 и играется через winmm. Если интернета нет,
  котик сам переключается на офлайн-голос и пишет причину в `pet.log`.

### Что учить

Словарь (4070 слов из тренажёра `english_for_programmers_gui`) разбит
на 18 блоков: темы (программирование, базы данных, деньги...), части
речи (глаголы, прилагательные...) и фразы (вежливость, академический
стиль). Меню "Что учить" позволяет галочками включать и выключать
блоки - котик показывает слова только из включённых. Внутри выбранных
блоков по-прежнему работают веса повторения из прогресса тренажёра:
трудные слова выпадают чаще. На карточке в подзаголовке видно, из
какого блока слово.

## Сборка exe (опционально, сейчас заблокировано Kaspersky)

```text
pyinstaller --onedir --windowed --name KisunchikPet --paths . --icon assets/icon.ico --add-data "assets;assets" run.py
```

Сборка только `--onedir`, не `--onefile`: onefile распаковывает себя
во временную папку при каждом запуске, Kaspersky это блокирует
("Could not create temporary directory!"). Иконка собирается из
мордочки котика скриптом `tools/make_icon.py`.

Настройки `settings.json` и журнал `pet.log` программа хранит рядом
с собой: у exe - в его папке, при запуске из исходников - в корне
проекта.

## Структура

| Файл | Что делает |
|---|---|
| `run.py` | точка входа: включает честные пиксели (DPI) и запускает приложение |
| `core/atlas.py` | `SpriteAtlas` - режет ленту спрайтов на кадры |
| `core/tutor.py` | `EnglishTutor`, `Word` - взвешенный выбор слов с фильтром по блокам |
| `core/speech.py` | `Speaker` - озвучка: офлайн SAPI SpVoice (ctypes COM) и онлайн Google TTS |
| `core/bubble.py` | `BubbleImage` - рисует пузырь с текстом в PIL |
| `core/behavior.py` | `BehaviorPolicy` - когда гулять и баловаться |
| `core/autostart.py` | автозапуск: реестр, reg.exe или ярлык в автозагрузке |
| `gui/screen.py` | `VirtualScreen`, `ScreenArea` - все мониторы одним прямоугольником |
| `gui/renderer.py` | `LayeredRenderer` - прозрачное окно через UpdateLayeredWindow |
| `gui/window.py` | `PetWindow` - окно tkinter: мышь, меню, зоны клика |
| `gui/app.py` | `KisunchikApp` - главный цикл, связывает всё вместе |
| `assets/` | `spritesheet.png`, `pet.json`, `words.json`, `categories.json` |
| `tools/build_categories.py` | собирает `categories.json` (18 блоков слов) из текстов тренажёра |
| `tests/` | тесты unittest, включая тесты на реальном экране |

## Тесты

```text
python -m unittest discover -s tests -t .
```

66 тестов: атлас, репетитор, блоки слов и голоса, пузырь, настройки,
автозапуск (с поддельным реестром), поведение на виртуальном времени,
а также живые проверки на реальном экране (окно рисует красный квадрат -
снимок экрана обязан его увидеть) и готовность английского голоса.
